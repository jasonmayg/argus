## 🚀 使用指南

### 最简单的开始方式

```bash
# 1. 激活虚拟环境
source venv/bin/activate

# 2. 配置 API 密钥
nano .env  # 添加 ANTHROPIC_API_KEY

# 3. 运行系统
python daily_monitor.py

# 4. 设置自动化
bash setup_cron.sh
```

### 验证系统

```bash
# 检查所有组件
python fed_news_crawler.py
python fed_news_db.py
python daily_monitor.py

# 查看输出
cat data/fed_news/logs/daily_monitor_*.json
```

## 💡 最佳实践建议

### 每日维护

```bash
# 早上检查：Cron 是否按预期运行
tail -f data/fed_news/cron_logs/*

# 检查新闻数据库
sqlite3 data/fed_news/argus_news.db "SELECT COUNT(*) FROM news;"
```

### 每周维护

```bash
# 备份数据库
cp data/fed_news/argus_news.db backup_$(date +%Y%m%d).db

# 查看趋势
python -c "from fed_news_db import FedNewsDatabase; db = FedNewsDatabase(); print(db.get_statistics())"
```

### 每月维护

```bash
# 生成月报告
python fed_news_backtest.py

# 清理旧日志
rm data/fed_news/cron_logs/*_old.log
```
